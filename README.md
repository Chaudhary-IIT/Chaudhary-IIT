### 👋 Naman Kumar

Third-year B.Tech at **IIT Mandi**. I lead and build **Sootrank** — the academic ERP the
institute runs on. Course registration, grading, transcripts, and student records for
**4,000+ students**, the full faculty, and the administrative offices.

🔗 **Live:** [sootrank.iitmandi.ac.in](https://sootrank.iitmandi.ac.in/team/) &nbsp;·&nbsp; 🔒 Repository is private and institute-owned

<br/>

LDAP single sign-on across multiple

Role separation across students, faculty,

**⚡ Concurrency**
Registration that holds when thousands of
students hit the same slot inside a

on the paths that can't be allowed to race.

</td>

**🎯 Correctness**
Relative grading with one-click policy
application. Tamper-evident audit logging
via SHA-256 hash chains.

</td>

**🚀 Performance**
Audited 60+ admin views and eliminated
N+1 queries throughout — `select_related`,
`prefetch_related` with `only()`, and bulk
operations instead of per-row writes.
